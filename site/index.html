Take the tour

Built to be lived in.

Start anywhere

Pick a comparison, or just drop files in.

Choose a mode from the welcome screen, drag files or folders anywhere on the window, or open a comparison straight from the terminal.

differentialis a.swift b.swift
differentialis release-1.0 release-1.1
differentialis base.txt mine.txt theirs.txt

Text

See exactly what changed, down to the character.

Lines pair up across the split, changed characters light up, and long unchanged runs fold away. Switch between split and unified with ⌘U, and step through changes with ⌘] and ⌘[.

Paste Text New

Compare snippets without saving a single file.

Press ⌘T, paste into two side-by-side editors, and the diff updates as you type. The panes scroll together and show line numbers. Click a change and copy it across with ⌥⌘→ or ⌥⌘←, with full undo.

Images

Spot the pixel that moved.

Two-Up side by side, One-Up blink, a draggable Split, and a false-color Difference mode where only the changed pixels glow. Zoom and pan stay in sync, and ⌘1–⌘4 switch modes.

Folders

Diff entire directory trees.

Every file is tagged Added, Removed, Modified, or Identical. Show just the changes or everything, filter by name or status, and pick any file to see its diff right alongside.

Merge

Resolve conflicts against a common base.

Changes made on only one side merge on their own. Real conflicts wait for you: use left, right, both, or the base, or edit the result by hand before you save.

Git

History, changes, and any comparison you can name.

Browse commits and see what each one touched, or switch to your working changes, staged and unstaged. Compare… lines up any reference, commit, or the working copy against another, and saves it for later.

Themes

Light, dark, or both.

Follow the system or pick an appearance, then choose a theme for each: Differentialis, Mariana, Monokai, One Dark, Solarized, or GitHub. You can also build your own, import a .tmTheme, and set the code font, with ⌘+ / ⌘− or a pinch to resize.

FAQ

Questions, answered.

What is Differentialis?

Differentialis is a free, open-source Mac app for comparing and merging files. It shows the differences between two text files, pasted snippets, images, or folders, resolves three-way merges, and browses git history. It's built natively with SwiftUI and Liquid Glass for macOS 26.

Is Differentialis free?

Yes. Differentialis is free and open source under the MIT license. Download the Apple-notarized .dmg from GitHub Releases; there's no account, subscription, or telemetry.

Which Macs does Differentialis run on?

Differentialis requires macOS 26 Tahoe or later and runs natively on both Apple silicon and Intel Macs.

How do I compare two text files on a Mac?

In Differentialis, choose New Text Comparison (⌘N) and pick the two files, or drag both files onto the window. The diff shows the files side by side or unified, with changed characters highlighted. From Terminal, run differentialis file1 file2 after installing the command-line tool from the app menu.

Can I compare text without saving it to files?

Yes. Paste Text (⌘T) opens two side-by-side editors. Paste or type into each, and the diff updates as you edit. You can copy any change from one side to the other, with undo.

Can Differentialis compare images and folders?

Yes. Images can be compared in Two-Up, One-Up (blink), Split, and Difference modes, for PNG, JPEG, HEIC, and any other format macOS can open. Folder comparison scans both trees and marks every file as added, removed, modified, or identical, with a diff for each file.

Does Differentialis work with git?

Yes. Open a repository to browse its commit history and its staged and unstaged changes, and compare any branch, tag, or commit against another or against your working copy. Differentialis uses the git already on your Mac.

Can Differentialis do a three-way merge?

Yes. Choose a base, left, and right file. Changes made on only one side merge automatically, and conflicts are shown side by side so you can use left, right, both, or the base, or edit the result before saving. Unresolved conflicts are saved with standard conflict markers.

Get Differentialis.

Download the notarized .dmg, drag it to Applications, and open. After that it keeps itself up to date. No setup, no account, no telemetry.
